Exercise 00 - A basic display

This folder contains a minimal Flutter application that satisfies the exercise requirements:

- A text widget with a button below it, both centered horizontally and vertically.
- When the button is clicked, "Button pressed" is printed to the debug console (uses debugPrint).
- The layout adapts to narrow screens (simple responsive constraints).

How to run:

1. Ensure Flutter SDK is installed and available on PATH.
2. From this directory (mobileModule00/ex00), run:

   flutter pub get
   flutter run

Files of interest:
- lib/main.dart: the Flutter app entry point.
- pubspec.yaml: package manifest.
